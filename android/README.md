# QQMusic для Android

Первый нативный клиент: Kotlin, Jetpack Compose, Media3/ExoPlayer. Отдельный проект внутри основного репозитория; исходники теперь сохраняются в Git. Минимум Android 8.0 (API 26), сервер по умолчанию https://qqmusic.ru.

Работают вход по логину и паролю, восстановление сессии, библиотека с поиском и страницами по 100 треков, любимые, чтение плейлистов, очередь и перемотка. Плеер работает в отдельном MediaSessionService: закрытие экрана не пересоздаёт аудио. Системные команды переключают треки; предусмотрена дополнительная команда лайка, её расположение зависит от Android и оболочки. Веб и сервер обновлять ради клиента не требуется.

Это ранняя версия для проверки. Внешний каталог/скачивание, персональная волна, создание плейлистов, офлайн, восстановление очереди после уничтожения процесса и обновления APK из самого клиента пока не реализованы. Если файл ещё не проиндексирован Navidrome, запуск отключён. Импорт и регистрацию пока выполнять через сайт. Старое приложение HomeMusic этим APK не обновляется: новый applicationId — ru.qqmusic.app (debug: ru.qqmusic.app.debug), прежнего ключа подписи здесь нет.

## Сборка

Нужны JDK 17+ (рекомендуется 21), Android SDK platform 36 / build-tools 36.0.0. Android Studio умеет установить их. Открывать эту папку как Gradle-проект. SDK задаётся в local.properties (sdk.dir=...), ANDROID_HOME или ANDROID_SDK_ROOT. Gradle Wrapper 8.13 включён в репозиторий; зависимости закреплены.

```powershell
# Из корня основного репозитория, PowerShell 7:
pwsh -File scripts/release-android.ps1

# Или из android:
.\gradlew.bat testDebugUnitTest lintDebug assembleDebug
```

Linux/macOS: bash gradlew testDebugUnitTest lintDebug assembleDebug. Готовый debug APK: app/build/outputs/apk/debug/app-debug.apk. Установить на телефон через adb install -r <путь-к-apk>. При входе нужен действующий пользователь QQMusic и HTTPS-сервер с корректным сертификатом. Логин в браузере не переносится в приложение.

## Подпись

Debug подписывается стандартным локальным отладочным ключом и предназначен для тестирования. Для release создать собственный keystore и незакоммиченный android/keystore.properties:

```properties
storeFile=/absolute/private/path/qqmusic-release.jks
storePassword=local-secret
keyAlias=qqmusic
keyPassword=local-secret
```

```powershell
pwsh -File scripts/release-android.ps1 -Configuration Release -VersionName 0.1.0 -VersionCode 1
```

Release без signing-файла скрипт отклоняет. APK и SHA256SUMS копируются в reports/android. Скрипт ничего не загружает на сервер, не меняет MUSIC_ROOT/.apk и latest.json. Старый скрипт дельта-обновлений HomeMusic заменён сборкой нового клиента: протокола bsdiff у него пока нет. Для будущих обновлений сохранять applicationId, тот же keystore и увеличивать versionCode.

## Сессия и приёмка

Пароль не записывается на диск. Cookie зашифрована ключом Android Keystore, резервное копирование приложения отключено. Один cookie jar обслуживает API и аудио. Разрешён только выбранный HTTPS origin; переходы на другие серверы автоматически не выполняются, произвольные сертификаты не принимаются. Выход очищает плеер и сессию. Смена сервера требует нового входа.

Перед распространением проверить на настоящем телефоне: вход/выход и повторный запуск, русский поиск, любимые и плейлисты, несколько треков подряд, перемотку, фон и экран блокировки, Bluetooth/отключение наушников, потерю сети, истечение сессии. Наличие собранного APK само по себе не подтверждает эти проверки.


## Проверка воспроизведения на Android

В CI добавлен эмулятор Android 15 (API 35). Инструментальный тест открывает настоящий экран библиотеки, нажимает трек и проверяет путь MediaController → MediaSessionService → HTTPS с session cookie → декодер WAV → продвижение аудиочасов. Затем проверяются перемотка, следующий трек, лайк и продолжение после закрытия Activity. Используются только локальные тестовые данные, отдельный HTTPS-сервер и временный сертификат; аккаунты qqmusic.ru не затрагиваются.

Локально с подключённым тестовым устройством/эмулятором: bash gradlew connectedDebugAndroidTest. На рабочем телефоне тест не запускать: для него предназначена отдельная тестовая установка.
