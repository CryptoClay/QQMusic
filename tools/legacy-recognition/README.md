# Устаревший инструмент распознавания

Этот необязательный инструмент сохранён отдельно от серверной и браузерной приёмки. Он не запускается в CI и не входит в стабильный пользовательский сценарий. Папки screenshots, results и локальный expected.json исключены из Git.

Для отдельной проверки подготовить screenshots и expected.json по образцу expected.example.json, затем из hub выполнить:

```powershell
uv run python ../tools/legacy-recognition/run_eval.py --help
```

Инструмент может обращаться к настроенному внешнему сервису и расходовать его лимиты. Для проверки QQMusic используйте tests/browser_server.py и web/e2e — они работают с собственными данными без внешнего каталога.
