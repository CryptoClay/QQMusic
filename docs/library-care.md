# Проверка и редактирование общей библиотеки

Администратор открывает **Настройки → Проверка библиотеки** (`#/library-health`). Экран проверяет записи, которыми управляет Hub: файлы, добавленные через QQMusic. Файлы, вручную добавленные только в Navidrome, в этот отчёт не входят.

Показаны отсутствующие файлы, записи без связи с Navidrome, похожие треки и повторяющиеся альбомы. Треки сравниваются по исполнителю, названию, признаку 18+ и длительности с допуском три секунды. Live/remix/clean/«без цензуры» из названий не удаляются; неизвестная длительность не приравнивается к известной. Это кандидаты для ручного сравнения, а не доказательство идентичного аудио.

Из группы можно открыть альбом и исправить теги. Повторяющиеся альбомы можно объединить, вручную выбрав основной. Все треки, файлы и UUID треков сохраняются. **Аудиокопии автоматически не удаляются и не схлопываются в один трек.** Альбомные лайки и ссылки после переноса могут потребовать обновления; предупреждение показано до применения.

## Предпросмотр

Редактор альбома и трека, перенос треков и объединение альбомов сначала вызывают `POST /api/library/preview`. Веб показывает изменения «было → станет», основной альбом, число затронутых треков, полный список файлов и предупреждения. Отмена ничего не записывает.

Предпросмотр действителен десять минут и привязан к администратору. `POST /api/library/apply` проверяет токен и повторно сверяет записи базы, размеры/время изменения файлов и содержимое каталогов под блокировкой библиотеки. При изменении библиотеки нужно открыть предпросмотр заново. Отсутствующий исходный файл блокирует редактирование; операция ограничена 500 треками.

На время применения создаются копии затрагиваемых файлов и обложек в `MUSIC_ROOT/staging/library-edit-*`. Требуется дополнительное свободное место примерно по объёму изменяемых файлов. Если редактирование прерывается ошибкой, файлы возвращаются, транзакция базы откатывается, восстановительные копии с `manifest.json` сохраняются для диагностики. После успеха временная копия удаляется. Это защита от ошибки операции, а не замена резервной копии при аварии компьютера.

Очищаемые поля (год, жанр, номера, неизвестный признак 18+) действительно очищаются и в базе, и в тегах. Изменение жанра альбома распространяется на все его треки; изменение исполнителя альбома не подменяет индивидуальных исполнителей треков.

Общую библиотеку редактирует администратор. Обычные пользователи продолжают слушать, скачивать, загружать музыку, вести собственные плейлисты и лайки. Прежние API редактирования сохранены для совместимости, но тоже требуют администратора; веб использует предпросмотр.

## Проверка после переименования, 13 ноября 2026

На действующей установке без перезапуска проверены: целостность SQLite, 71 трек, 71 существующий файл, отсутствие потерянных связей с Navidrome, 18 лайков, один плейлист с 50 связанными записями и чтение 1024 байт аудио с HTTP 206. Никакие теги или файлы рабочей библиотеки при этой проверке не изменялись.
