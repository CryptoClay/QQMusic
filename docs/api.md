# Документация HTTP API

Актуальные адреса, параметры и ответы генерируются из серверного кода:

- `/api/docs` — интерактивная документация;
- `/api/openapi.json` — машиночитаемая схема;
- `hub/app/api/` — обработчики;
- `hub/app/api/schemas.py` и модели рядом с обработчиками — типы данных.

Старый вручную переписанный каталог запросов удалён: он расходился с реализацией. Схема формируется FastAPI при запуске и соответствует установленной версии.

Вход через `/api/auth/login` создаёт cookie `qqmusic_session` с HttpOnly и SameSite=Lax. По HTTPS и в публичном режиме она также Secure. Приватные запросы без сессии получают 401, административные запросы обычного пользователя — 403. Старое имя cookie принимается для совместимости установок. Выход отзывает обе совместимые сессии.

Записывающие браузерные запросы должны иметь тот же Origin, что адрес сервиса. В публичном режиме дополнительно проверяется Host и ограничиваются попытки входа. Нативные клиенты без Origin по-прежнему поддерживаются; браузерные cross-site запросы исключения не получают.

Основные группы: `/api/auth`, `/api/search`, `/api/library`, `/api/downloads`, `/api/listen`, `/api/community`, `/api/player`, `/api/music`, `/api/admin`. Набор конкретных методов смотрите в схеме установленного сервера.

Работая с документацией, не публиковать cookie, пароли, экспорт подключений и приватные ссылки. Примеры и диагностические отчёты должны использовать отдельный тестовый аккаунт.
